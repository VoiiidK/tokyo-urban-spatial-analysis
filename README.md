# tokyo-urban-spatial-analysis
A reproducible spatial analysis of pedestrian access to rail stations in Asagaya, Tokyo.

# Tokyo Urban Spatical Analysis Platform

## Research question

How does local street-network connectivity influence walking accessibility to railway stations in the Asagaya area of Tokyo?

## Study area
A 1–2 km radius of circle around Asagaya Station.

## First-version data
- OpenStreetMap: pedestrian street network, intersections, railway stations
- Later extension: e-Stat population data and MLIT land-use data

## First-version outputs
- Pedestrian network map
- Station walking-accessibility map
- Intersection-density map
- Scatter plot and simple regression result
